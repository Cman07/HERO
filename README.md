# HERO
Hazard &amp; Emergency Response Organizers for Microsoft and CCI Innovation Challenge

Run the local site from this directory with `npm start`, then open http://127.0.0.1:3000.

The visual system is documented in [DESIGN.md](DESIGN.md). The shared stylesheet uses a locally hosted DM Sans font and community illustration across the home, help, preparedness, and account pages. Font licensing is included in `assets/fonts/OFL.txt`.

See [FLOOD_GUIDE_README.md](FLOOD_GUIDE_README.md) for service configuration, storage, and feature details.
